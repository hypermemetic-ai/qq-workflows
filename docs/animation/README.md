# Animation from reference to play

Start with the last take the owner saw, the reference at its original speed, and the inputs that play the move in the game. Save enough to play the same comparison after an edit. A good first question is “What does the character do with their weight as the step starts?” It gives an animator something visible to draw and a reviewer something visible to judge.

| When the work is… | Use |
| --- | --- |
| Reproducing a performance, diagnosing an awkward passage, or reviewing a take | [From first viewing to a played comparison](reference-review.md) |
| Trying an editor release, cleaning capture or making a layered correction | [Cascadeur in the animation workflow](cascadeur.md) |
| A cuff, shoulder or hem moves oddly while the joints look sound | Play the same pose with the costume and the rig visible. Then use [the modeling workflow for clothing](../modeling/form.md). |

## What to carry forward

The project owns a private animation notebook in a durable location. Its front page should lead the next animator to the accepted game revision, the editable source or generator, a playable input, the relevant reference views and the verdict. Keep one revealing comparison with the note. A link into a disposable capture folder is a convenience until the evidence is copied somewhere durable.

Write down what changed the decision. For a sidestep, a useful note might say “the earlier dip reads in both directions. The tighter camera hides the lead foot on the near side. Use the wide camera for that foot and the ordinary camera for the verdict.” That tells the next artist where to look, what to preserve and where the evidence ends. Record a failed approach if trying it again would cost real time. When the same failure occurs across moves, carry the lesson, or a tool that exposes it, back here.
