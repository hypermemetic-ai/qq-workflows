# Character modeling workflow

Start with the whole character. Open the owner's chosen reference, the last version they saw, and the editable source that produced it. Find out which features they liked. A rejected version can still contain a useful groom, camera fit, or rig. Write down the verdict at the scope it actually covered.

**What would someone see if this edit succeeded?** For “she looks tired,” inspect how the upper lid crosses the iris, the lower lid's thickness, the color under it, and the shadow from the brow. A modeler can distinguish these without asking the art director to translate “tired” into slider values. For “the jacket looks like a T-shirt,” compare the opening, silhouette and compression folds in a pose where the fabric has weight. A stronger wrinkle map alone cannot make a sleeve stand away from the arm.

## How a revision moves

1. **Choose the reference for the question.** Identity art supplies the face. Footage of a well-rendered character supplies examples of how wet eyes and skin respond to light. A product photo can supply construction details. Keep their roles legible. Open the original images at enough resolution to see the relevant evidence.
2. **Set up the observation before editing.** Match camera perspective, pose and framing. Put the assembled character through the intended renderer. Keep an untouched control. Compare the head at portrait size and as part of the fighter. A correct landmark and an attractive whole face are separate observations.
3. **Find what owns the appearance.** Use the cheapest meaningful control. Turn off a color layer, hold the geometry still and move the light, take a cross-section, identify which guide owns a visible card, or show a garment without wrinkle maps. If two causes still fit the evidence, keep both live.
4. **Edit a source you can reopen.** Geometry, grooming guides, pattern panels and layered materials each carry different decisions. Save the change independently. Export it, render it, reopen it and make a second edit. Check untouched neighbors and movement in the delivered asset.
5. **Compare the whole result yourself.** If a change makes the character read worse, keep the record of what it taught you and continue from a better source. Use owner time for a meaningful candidate, a real artistic fork, or a resource decision. Only the owner's verdict confers acceptance.

Project material belongs in the project's private notebook. Keep its entry point in a stable location outside temporary work folders. Include current references, verdicts, source versions, runnable commands, important dead ends and pointers to the evidence. Keep this public guide about transferable practice.
