# Workflow ownership

This repository owns workflow machinery, including the native Git-status helper. Failures in that machinery are product defects here; prefer proportionate corrections.

## Native context

Native authority is stock Codex and byte-unmodified OpenSpec core skills/schema. Retained legacy role prompts and tools belong to the retirement program. `docs/native-entry.md` maps that program and its private operator checkpoint; consult it when a task affects migration or retirement.

Preserve owned consumers until drained. Do not interrupt the independent ISO/Music native streams. DecIQ and DecIQ Logic are paid contract work, outside this cleanup.

For character modeling work, start at [the modeling workflow](docs/modeling/README.md) and the project's private current-state note. The workflow routes to face, material, groom, clothing, review and automation guidance by the job at hand.

For animation work, start at [the animation workflow](docs/animation/README.md) and the project's private current-state note. Use the played take and its reference to decide what needs changing.
