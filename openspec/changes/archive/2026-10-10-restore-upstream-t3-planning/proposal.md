# Proposal

## Why

The T3 adapter altered the selected grilling method based on an unsupported
phone preference and left competing OpenSpec interview instructions and worker
phase ownership ambiguous. The user requests original instructions with only
concise, bounded integration.

## What Changes

- Replace adapted questioning with the pinned, byte-original grilling source.
- Reduce the custom skill to phase routing and research/implementation ownership.
- Keep OpenSpec explore out of this grilling round; retain original OpenSpec
  capture, apply, sync and archive instructions and their handoffs.
- Make the architect the sole OpenSpec phase owner; delegates return evidence or
  implementation results rather than independently operating the change lifecycle.
- Refresh T3's instructions and document the corrected source boundaries.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `t3-openspec-architecture`: Original grilling controls architecture conversations;
  the architect owns OpenSpec phases and distinct delegation contracts.

## Impact

The T3 adapter, profile instructions, provenance description and operational
documentation change. OpenSpec core skills/schema, the pinned grilling source,
permissions, model selection, project files and other agent homes remain unchanged.
